# 方向卡

当你说不出一个来自题材的具体方向时，从这里选一张卡，作为作品的骨架。

## 怎么选

1. **按题材的真实世界选，不按「安全」选。** 问：这个题材的人、物、场所，最接近哪张卡描述的世界？
   例：一个本地图书馆活动页 → 档案印刷品 / 报纸版面；一个户外装备品牌 → 地图制图 / 工业标识；一个儿童绘本网站 → 剪纸拼贴 / 孟菲斯。
2. **两张都合适时，选不那么常见的那张。** 「编辑杂志」「柔和生活」最容易被选中，也最容易平庸。
3. **只选一张。** 不要混合三张卡；最多从第二张卡借一个细节。
4. **选完必须做一件事：从题材里取一个具体元素融进去**（一种真实物件的形状、一个行业特有的排版习惯、一种材料的纹理）。卡给骨架，题材给血肉。
5. 卡里的字体和色板是起点：可以调色温、换字体，但保持卡的气质。字号、间距、版式结构仍然按 `floor-web-ui.md`。

每张卡的格式：**适合** / **骨架** / **字体** / **色板** / **材质与细节** / **易砸点**。

---

### 1. 档案印刷品
- **适合**：历史、文化机构、图书馆、研究、有年代感的品牌。
- **骨架**：像一份装订的文件或卡片目录。编号、分类号、日期栏；左侧窄栏放元信息，右侧宽栏放正文。
- **字体**：标题用宋体或衬线体；元信息用等宽字体（`"Courier Prime", "IBM Plex Mono", monospace`）。
- **色板**：纸 `#EFE9DC`，墨 `#1F1D1A`，褪色红章 `#A63A2B`，铅灰 `#6E6A62`。
- **材质与细节**：细横线分栏、打字机字感、印章、手写批注一两处、轻微纸张纹理（极淡）。
- **易砸点**：做旧过度（大面积污渍、撕边）变成廉价道具；元信息铺满全页抢了正文。

### 2. 瑞士国际主义
- **适合**：设计、建筑、展览、理性的科技或工具产品。
- **骨架**：严格的多列网格（8 或 12 列），非对称排布；大号无衬线字作为图形本身；大量留白。
- **字体**：一个无衬线字族贯穿全站（`"Inter", "Helvetica Neue", "Noto Sans CJK SC", sans-serif`），用字号和字重做层级。
- **色板**：白 `#F5F5F2`，黑 `#111111`，一个纯正强调色（红 `#E2231A` 或蓝 `#0047BB`）。
- **材质与细节**：无阴影、无圆角；细线；数字编号；文字左对齐，右边不齐。
- **易砸点**：只有网格没有张力，变成普通企业官网。需要一个尺度极端的元素（超大数字或标题）。

### 3. 编辑杂志
- **适合**：内容品牌、长文、文化生活方式、作者个人站。
- **骨架**：大标题和大图主导，正文窄栏，引文放大穿插，节奏有快有慢。
- **字体**：标题用高对比衬线体（`"Playfair Display", "Noto Serif CJK SC", serif`），正文用易读的衬线或无衬线体。
- **色板**：象牙 `#F7F3EC`，深褐黑 `#22201C`，一个低饱和强调色（橄榄 `#6B6B3A` 或砖红 `#9C4A32`）。
- **材质与细节**：首字下沉、栏间细线、图片说明小字、页眉页码式的元信息。
- **易砸点**：最容易平庸的一张卡。必须有一处大胆的版式决定（如整屏只有一个巨大标题，或图片出血）。

### 4. 粗野主义网页
- **适合**：独立项目、实验性工具、艺术活动、反主流品牌。
- **骨架**：裸露的结构，粗边框，块状堆叠，系统默认感；不追求「好看」，追求直接。
- **字体**：等宽字体或系统默认字体；标题极大极粗。
- **色板**：白 `#FFFFFF` 或纯色底，黑 `#000000`，一个刺眼的颜色（`#FFEB00` / `#00FF66` / `#FF3B00`）。
- **材质与细节**：2–4px 实心黑边框，硬阴影（偏移不模糊），下划线链接，无圆角无渐变。
- **易砸点**：变成「乱」。粗野主义仍需要严格的对齐和一致的边框规则。

### 5. 科学仪器图谱
- **适合**：数据、科学、工程、天文、气象、精密产品。
- **骨架**：像一张仪器记录纸或技术图版：图号、刻度、坐标、图例、剖面图。
- **字体**：等宽字体做数据和标注；无衬线体做标题。
- **色板**：绘图纸 `#F2F0E9`，碳黑 `#15171A`，蓝晒网格 `#2E5C8A`（低透明），一个警示色 `#E8481C`。
- **材质与细节**：0.5–1px 细线、刻度尺、圆形罗盘、编号标注线、淡网格底。
- **易砸点**：伪数据铺满全屏，没有一个主图。必须有一个占面积最大的核心图形，其他数据都是陪衬。

### 6. 东方留白
- **适合**：茶、书法、传统文化、冥想、诗歌、极简高端品牌。
- **骨架**：大面积留白，主体偏置；竖排标题（`writing-mode: vertical-rl`）；内容极少。
- **字体**：宋体或楷体（`"Noto Serif CJK SC"`, `"AR PL UKai CN"`）。
- **色板**：宣纸 `#F3EFE6`，墨 `#1E1E1C`，淡墨 `#8A877F`，朱砂印 `#B23A2A`（只用一处）。
- **材质与细节**：一枚印章、一处墨迹或细线山形、竖排小字题跋。
- **易砸点**：「空」变成「没做完」。留白必须围绕一个有分量的主体；同时避免水墨山水、仙鹤祥云等陈词滥调。

### 7. 剪纸拼贴
- **适合**：儿童、教育、社区、节庆、手作、温暖的公共项目。
- **骨架**：平面色块层叠，像彩纸剪出来贴上去；形状简单有力，轻微不规则。
- **字体**：圆润或手写感的标题；正文用清晰的无衬线体。
- **色板**：底 `#F4EDE1`，3–4 个饱和但不刺眼的色（`#D9573B` / `#2F6B5E` / `#E8B547` / `#3B3A6B`）。
- **材质与细节**：纸片轻微投影（偏移小、无模糊或极少模糊）、剪刀边的不规则轮廓、纸张纹理。
- **易砸点**：颜色过多变成幼稚；形状太精确就失去手作感。

### 8. 木刻 / 孔版印刷
- **适合**：音乐、演出、抗议、手工啤酒、独立出版、强情绪主题。
- **骨架**：强烈的黑白对比，粗刀痕线条；双色套印，故意错位 2–3px。
- **字体**：粗重的衬线或手刻感标题；正文简洁。
- **色板**：未漂白纸 `#E9E0CC`，油墨黑 `#151413`，套印色一种（红 `#D9361E` 或蓝 `#1F4FA0`），叠印用 `mix-blend-mode: multiply`。
- **材质与细节**：粗颗粒噪点、刀痕排线、套印错位、墨色不均。
- **易砸点**：所有区域同样粗犷就没有重点。信息区要干净可读。

### 9. 工业标识
- **适合**：户外、物流、工具、硬件、交通、安全相关。
- **骨架**：像设备铭牌或场地标识：编号、警示条、大号代码、模块化面板。
- **字体**：窄体无衬线或模板字（`"Barlow Condensed", "DIN", "Noto Sans CJK SC"`），全大写编号。
- **色板**：混凝土灰 `#D4D2CC`，黑 `#1A1A1A`，安全黄 `#F2B90C` 或安全橙 `#E85D1A`。
- **材质与细节**：斜纹警示条（少量）、铆钉点、铭牌边框、序列号。
- **易砸点**：警示条和黄色用太多，像施工现场。黄色只给关键元素。

### 10. 包豪斯几何
- **适合**：教育、艺术活动、建筑、品牌重塑、儿童但偏理性。
- **骨架**：圆、方、三角作为构图主体；不对称平衡；文字与几何形互相咬合。
- **字体**：几何无衬线体（`"Futura", "Jost", "Noto Sans CJK SC"`）。
- **色板**：米白 `#F1ECE2`，黑 `#1B1B1B`，原色红 `#D13B2A`、黄 `#EDB72F`、蓝 `#1E4E9C`。
- **材质与细节**：大几何块、粗直线、文字旋转 90°。
- **易砸点**：几何形只当装饰贴在角落。它们应该是构图骨架。

### 11. 自然史图版
- **适合**：植物、动物、户外、环保、博物、食物原料。
- **骨架**：像博物学图鉴：一个精细的主体居中，周围是编号标注、拉丁学名、分类信息。
- **字体**：衬线体，学名用斜体；小号说明文字。
- **色板**：旧纸 `#F1EADB`，深墨绿 `#2C3A2E`，赭石 `#A86B3C`，淡水彩色若干。
- **材质与细节**：细线描主体、编号引线、图版边框、一处手写标签。
- **易砸点**：主体画得粗糙，整张卡就塌了。主体宁可简单，也要线条干净。

### 12. 柔和生活
- **适合**：家居、日用品、护理、咖啡茶饮、慢生活品牌。
- **骨架**：宽松留白，照片或柔和插图为主，信息极少，节奏缓慢。
- **字体**：细到中等字重的无衬线体或温和衬线体。
- **色板**：燕麦 `#EEE8DD`，暖灰褐 `#5A524A`，一个自然色（鼠尾草绿 `#8A9A7B` 或陶土 `#B8775A`）。
- **材质与细节**：亚麻、纸、木的细微纹理；圆角小；阴影几乎没有。
- **易砸点**：最容易像所有其他品牌。必须加入一个题材独有的细节，否则就是模板。

### 13. 孟菲斯 / 波普
- **适合**：年轻品牌、娱乐、潮流、游戏、活动宣传。
- **骨架**：大胆的形状、图案和颜色碰撞；元素倾斜、重叠；高能量。
- **字体**：粗圆或粗黑的展示字体；正文保持清晰。
- **色板**：粉 `#F5A6C0`，黄 `#FFD23F`，青 `#2EC4B6`，黑 `#1A1A1A`，底色可以是其中之一。
- **材质与细节**：波点、波浪线、锯齿、硬投影、黑色粗描边。
- **易砸点**：每处都满就成了噪音。留出一块干净的区域放核心信息。

### 14. 装饰艺术（Art Deco）
- **适合**：酒店、酒类、剧院、珠宝、复古高端、典礼。
- **骨架**：强对称、放射线、阶梯形、拱形框；垂直感。
- **字体**：高挑的几何衬线或展示字体，全大写宽字距。
- **色板**：深墨绿 `#14302A` 或深海军 `#141B2D`，香槟金 `#C8A96A`，象牙 `#EFE6D2`。
- **材质与细节**：细金线框、扇形放射、几何边饰。
- **易砸点**：金色渐变和发光会立刻变廉价。金色用平涂或极细线。

### 15. 速写本 / 手记
- **适合**：个人站、旅行、教育、创意过程、手工、工作坊。
- **骨架**：像一页笔记本：手写标注、箭头、草图、贴纸、胶带。
- **字体**：正文用清晰字体；手写体只用于少量批注。
- **色板**：纸 `#FAF7F0`，铅笔灰 `#4A4A48`，一支彩色笔（蓝 `#2B59C3` 或红 `#D2452D`）。
- **材质与细节**：方格或横线纸底（极淡）、手绘箭头和圈注（SVG 路径带轻微抖动）、胶带。
- **易砸点**：手写体用作正文，难读；手绘元素过多显得幼稚。

### 16. 地图 / 制图
- **适合**：旅行、城市、户外、物流、地方品牌、社区项目。
- **骨架**：以地图或路线图为主视觉；等高线、图例、比例尺、坐标网格组织信息。
- **字体**：无衬线体做地名；斜体或小号大写做地理标注。
- **色板**：地图纸 `#F0EDE4`，等高线棕 `#B08860`，水域蓝 `#8FB3C9`，路线红 `#D2452D`。
- **材质与细节**：等高线、虚线路线、图钉标记、指北针、图例框。
- **易砸点**：地图元素只是背景纹理，和内容无关。路线或地点应该承载真实信息。

### 17. 报纸版面
- **适合**：新闻、社区公告、活动合集、年度回顾、信息密度高的页面。
- **骨架**：报头、多栏正文、粗细线分隔、大标题 + 导语 + 正文的层级。
- **字体**：报头用粗衬线；标题用紧凑衬线或黑体；正文用小号衬线。
- **色板**：新闻纸 `#F2EFE8`，墨 `#141414`，可选一个专色（红 `#C0272D`）。
- **材质与细节**：栏线、日期期号、图片网点（halftone）、跨栏大标题。
- **易砸点**：栏太多字太小，移动端完全不可读。移动端改为单栏。

### 18. 暗房 / 胶片
- **适合**：摄影、电影、音乐、夜生活、叙事类作品。
- **骨架**：大幅图像主导，文字少而小，像影片字幕或底片边缘信息。
- **字体**：细无衬线或等宽体，小号，宽字距。
- **色板**：近黑 `#121110`，暖白 `#EDE6D8`，安全灯红 `#9E2B25`（极少）。
- **材质与细节**：胶片颗粒、底片齿孔和编号、轻微暗角、帧号。
- **易砸点**：深色底加发光文字会落回 AI 惯性组合。不用发光，靠明暗和颗粒。
