# 保底手艺：网页 / UI

已有项目优先复用现有设计系统、组件和 token；以下用于新建或缺项时的默认值。目的只有一个：**让作品在没有特别理由时，也是扎实的。**
方向卡或你自己的方向会决定「长什么样」；这份文件决定「做得稳不稳」。有理由时可以打破任何一条。

---

## 0. 先建 token，再写页面

开始写 CSS 时，先把下面这组变量定下来，后面只用变量，不临时写数字。这一步最能防止页面「各处差一点」。

```css
:root {
  /* 字号：选一个比例，最多用 5 档 */
  --fs-sm: 0.8125rem;   /* 13px 辅助信息 */
  --fs-base: 1rem;      /* 16px 正文 */
  --fs-lg: 1.25rem;     /* 20px 小标题 */
  --fs-xl: 2rem;        /* 32px 区块标题 */
  --fs-hero: clamp(2.75rem, 6vw, 5rem); /* 唯一的主角 */

  /* 间距：只用这几档 */
  --s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px;
  --s-5: 24px; --s-6: 32px; --s-7: 48px; --s-8: 64px; --s-9: 96px;

  /* 颜色：先中性色，后强调色 */
  --bg: ...; --surface: ...; --text: ...; --text-2: ...; --line: ...;
  --accent: ...;

  --radius: ...;  /* 全站一个值 */
}
```

## 1. 字体与排版

- **字族最多两个**：一个用于标题，一个用于正文；或者同一字族用字重区分。字重最多 2–3 种。
- **字号比例**：界面类用约 1.2–1.25 倍递进；落地页、杂志感页面可以用 1.333–1.5 倍，让主标题和正文拉开明显差距。**主标题至少是正文的 2.5 倍**，否则没有层级。
- **行高**：正文 1.5–1.7；中文正文 1.7–1.8；大标题 1.05–1.25。字越大，行高越小。
- **行宽**：拉丁文每行 45–75 字符；中文每行 25–40 字，用 `max-width: 36em` 左右控制。阅读栏宽一般 640–720px。
- **字距**：全大写的英文小标签加 `letter-spacing: 0.06–0.12em`；大号拉丁标题可以略收紧（-0.01 到 -0.02em）；中文一般不加字距，标题最多 0.02–0.05em。
- **中文字体回退栈**（先用本机已有字体，`fc-list :lang=zh` 可查）：
  - 黑体：`"Noto Sans CJK SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
  - 宋体：`"Noto Serif CJK SC", "Source Han Serif SC", "Songti SC", "SimSun", serif`
  - 楷体：`"AR PL UKai CN", "Kaiti SC", "KaiTi", serif`
- 有网络时可用 Web 字体；没有网络时**不要依赖外链字体**，否则截图里会是回退字体，和设计不符。
- 中文避免：标点打头、单字孤行、中英文之间挤在一起（可加细空格或 `text-autospace`，不支持时手动加空格）。

## 2. 间距与分组

- **只用 token 里的间距值。** 不出现 13px、27px 这种随手数。
- **内小外大**：同组元素之间的间距 < 组与组之间 < 区块与区块之间。每一级大约是上一级的 2 倍。分组靠间距表达，不必每组都加边框或背景。
- 区块之间留足：桌面端区块间距一般 `--s-8` 到 `--s-9`（64–96px），移动端减半。
- 页面内容最大宽度 1120–1280px，两侧留白至少 `--s-5`（移动端 `--s-4`）。

## 3. 颜色

按这个顺序搭：

1. **背景**：纯白和纯黑都少用。浅色背景用略带色温的白（如 `#F6F4EF`、`#F4F6F8`）；深色背景用明度 8–14% 的深色（如 `#121316`、`#15171C`），不用 `#000`。
2. **表面**（卡片、面板）：和背景只差一点明度，靠细微差别分层。
3. **文字**：主文字和背景对比度 ≥ 4.5:1（大标题 ≥ 3:1）。浅底不用纯黑字，用 `#1A1A1A` 一类；次要文字是主文字降低明度或透明度，不要换成另一种色相。
4. **线条**：比表面再深或浅一档，非常淡。
5. **强调色**：**只有一个**，占画面面积不超过约 10%，只给最重要的动作或信息。深色底上强调色要降低饱和度，否则刺眼、廉价。
6. 语义色（成功、警告、错误）只在确实需要时用，并压低饱和度，与整体色温统一。

推荐用 `oklch()` 推导同色系的深浅档，明度变化会比较均匀。

## 4. 版式骨架

先选一种骨架，再填内容。

**落地页 / 介绍页**
1. 首屏：一句核心信息 + 一个主要动作 + 一个主视觉。首屏只有一个主角。
2. 证据：具体内容、案例、数据（用真实感的内容，不用占位文字）。
3. 细节：功能或内容展开。节奏要有变化：不要每个区块都是「标题 + 三列卡片」。
4. 结尾：重复主要动作。

**应用界面（App / 工具）**
- 每屏只有一个主要操作，视觉上最突出；次要操作降级为文字按钮或图标。
- 信息按任务顺序从上到下排列，最常用的放在拇指或视线最先到达的位置。

**仪表盘 / 数据页**
- 最重要的一个数字放左上，最大。其余指标降级。
- 图表少而大，好过多而小。

**展示页 / 作品集 / 索引页**
- 作品是主角，说明文字安静退后。每件作品一个标题加一两句话。

## 5. 组件细节

- **圆角全站一个值**：硬朗、编辑感用 0–4px；中性用 6–10px；只有明确的亲和风格才用 12px 以上。不要大小圆角混用。
- **分层方式选一种为主**：用细线分隔，或用背景明度分隔，或用阴影，不要三种同时大量用。
- **阴影**：最多两档，低透明度（如 `0 1px 2px rgb(0 0 0 / .06), 0 4px 12px rgb(0 0 0 / .06)`），光源方向一致（从上方）。深色底上阴影几乎无效，靠表面明度分层。
- **按钮**：每个视图一个主按钮。高度 40–48px，水平内边距约为高度的 0.5–0.75 倍。
- **图标**：同一套图标，线宽一致，和正文字重相配。不用 emoji 充当图标，除非风格就是如此。
- **状态**：可点击元素要有 hover 和清晰可见的 focus 样式。

## 6. 内容

- **不用 Lorem ipsum 和「标题一、标题二」。** 写符合场景的真实内容，长短不一。真实内容会暴露排版问题，占位文字会掩盖问题。
- 没有图片素材时，用纯色块、简洁的 SVG 图形或排版本身撑起画面；不要放灰色占位框。

## 7. 响应式

- 至少检查两个宽度：1440 和 390。
- 390 宽度下：没有横向滚动；正文不小于 15px；点击目标不小于 44×44px；多列变单列时检查顺序是否合理。
- 用 `clamp()` 处理大标题字号，避免移动端标题溢出。
